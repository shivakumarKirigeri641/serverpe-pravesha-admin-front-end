# serverpe-pravesha-admin-front-end

Admin panel for **Pravesha** (ಪ್ರವೇಶ) — WhatsApp-based QR entry ticketing for
tourist places.

Used by the department and by ServerPe to run a site: live occupancy and
scanning, bookings and QR status, gate log and staff checks, customer and
vehicle analytics, revenue and settlement, daily/weekly/monthly reports,
capacity and pricing configuration, staff accounts, and the audit trail.

Backend: [serverpe-pravesha-back-end](https://github.com/shivakumarKirigeri641/serverpe-pravesha-back-end)

## Running locally

```bash
npm install
npm run dev
```

The panel talks to the backend under `/admin/api`. Point it at a running
backend (default port 5005) before signing in.
